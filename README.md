# Scrimba Project - Langbase AI Integration

## What It Is
This project is a Node.js application designed to demonstrate the capabilities of **Langbase**. It currently serves as a backend utility to manage AI "Memories" (knowledge bases).

Key features implemented so far:
- **Memory Creation**: Scripts to initialize new memories in Langbase.
- **Document Management**: Tools to upload text documents (`upload-docs.ts`) to the memory.
- **Inspection**: Utilities to list and verify stored documents (`list-docs.ts`).

It acts as the foundational data layer for an AI application, handling the ingestion and organization of context data.

## What It Is Going To Be
The vision for this project is to evolve into a **full-stack AI Assistant**.

Future roadmap includes:
1.  **Query Interface**: Implementing a script or API to ask questions against the uploaded memory (RAG - Retrieval Augmented Generation).
2.  **Frontend Integration**: Building a user-friendly web interface (likely using React/Next.js) to interact with the AI.
3.  **Dynamic Content**: allowing users to upload their own documents via the UI.
4.  **Advanced Reasoning**: Leveraging Langbase's pipes to create more complex AI workflows.
